# Spec: bridge dashboard note

Extend `tn serve` (serve.go) to render a live dashboard as a Markdown note inside the Obsidian vault, so the user can see agent sessions and pending work without leaving Obsidian. Match existing code style; stdlib only.

## Config

`~/.config/tn/serve.json` gains optional `"dashboardPath"` (absolute path to the .md file to write, e.g. `~/Documents/MyVault/Claude Sessions.md`). Empty/absent = dashboard disabled.

## Rendering triggers

- After every state mutation (register, deregister, message queued/delivered/acked, webhook-driven changes)
- Plus a 60s ticker (so alive→dead flips render without a mutation)
- Debounce: coalesce triggers, render at most once per 2s (timer-based, no busy loop)
- Write atomically: tmp file in same dir + rename (Obsidian must never see a partial file)

## Content (generated Markdown)

```
---
generated: true
---

> Auto-generated by `tn serve` — do not edit. Updated: 2026-08-17 12:04:31

## Sessions

| Session | Project | Status | Last seen | Queued | Attach |
|---|---|---|---|---|---|
| orchestrator-procfit | procfit | 🟢 alive | 12:04:10 | 2 | `tmux attach -t tn-procfit` |
| claude/foo-e2e | foo | ⚫ gone | 11:20:01 | 0 | — |
```

- Status: 🟢 alive (lastSeen < 90s), ⚫ gone. Deregistered agents: show only if they still have non-acked messages, status ⚫.
- Queued = count of messages for that agent with status queued or delivered (i.e. not yet acked).
- Attach column: `tmux attach -t tn-<project>` only for agents named `orchestrator-<project>`, else `—`.

```
## Pending messages

- `msg-…` → **orchestrator-procfit** (queued, 3m): Task assigned: Fix login ([[TaskNotes/Fix login]])
- `msg-…` → **claude/foo-e2e** (delivered, 40s): @claude line text…
```

- All messages with status != acked, oldest first, text truncated to 120 chars.
- Age humanized (40s / 3m / 2h / 1d).
- If message has taskPath ending in `.md`: append wikilink `[[<path without .md>]]`.

```
## Recent activity

- 12:03 ✅ orchestrator-procfit acked msg-… — "response text…" ([[task link]])
```

- Last 10 acked messages, newest first, response truncated to 120 chars. Omit section if none.

Empty states: "_No sessions registered._" / "_No pending messages._"

## Implementation notes

- Rendering must read state under the existing mutex (snapshot copy, render outside lock).
- Humanized age + timestamp formatting: small helpers, unit-tested.
- Failures to write (vault missing, perms): log once per distinct error, don't crash, keep serving.
